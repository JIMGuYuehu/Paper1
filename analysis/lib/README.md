# Shared analysis functions

- `paper1_diagnostics.py`: ozone integration, NAM/AO, monthly-static-stability EP-flux handling, CRPS, sign agreement, and bootstrap definitions.
- `relationship_products.py`: figure-ready rankings, minima, windows, Pearson statistics, and OLS display fits.
- `figure15_combined.py`: Z300 and EP-flux low-ozone composites.
- `epflux_jucker.py`: GPLv3 Methods subset derived from Martin Jucker's `aostools`.
- `workflow_io.py`: portable input/work paths and validated NetCDF/CSV writers.
