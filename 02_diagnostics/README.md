# Diagnostics

Run the seven notebooks in numerical order. Each calculation block is preceded
by a markdown block stating its inputs, output and method.

- `01`: 30-70 hPa partial ozone, spring minima and event ranking
- `02`: fixed-EOF NAM and AO (= 1000 hPa NAM)
- `03`: Jucker pressure-coordinate EP flux
- `04`: MLS/WACCM ClO/ClOx and H2O anomalies
- `05`: spread, CRPS, RMSE, Pearson/OLS and figure-ready predictors
- `06`: January/February/March ensemble products
- `07`: Figure 15 Z300 and EP-flux bootstrap composites

Inputs come from `runtime/`; diagnostic outputs are written back there.
